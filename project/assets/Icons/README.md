# Icons

Lucide v0.460 (ISC license), restroked to 1.5px on the 24px grid, plus one Tabler Icons glyph (v3.19, MIT). These files are single-ink, stroked in `#4B6699` (`navy-500`) so they read on both page themes in this viewer; in the site, render icons inline with `mallardduck/blade-lucide-icons` so they take `currentColor`.

- **Interface**: arrow-right, arrow-up-right (external links only), chevron-down, chevron-right, menu, x, check, sun, moon, monitor, phone, mail, map-pin, calendar, clock, languages, quote, star (filled in ratings), play.
- **Status**: info, circle-check, triangle-alert, circle-alert — always next to words.
- **Practice areas**: car, truck, motorbike (Tabler — Lucide has no motorcycle), bike (bicycle), footprints (pedestrian), car-taxi-front (Uber & Lyft), wine (DUI), dog (dog bites), brain (brain injuries), baby (child injuries), package-x (defective products), hand-heart (neurodivergent advocacy). Wrongful death and slip-and-fall have no icon on purpose.
- **Credentials and media**: award, shield-check, graduation-cap, newspaper, mic.
- **Social**: linkedin, instagram, youtube, facebook. Lucide’s brand glyphs are deprecated upstream; if they disappear, use Simple Icons for these four only.

Sizes: 16px in buttons and badges, 20px default, 24px in practice cards. Never use emoji, gavels, scales or columns.
